# Таємниця кондитерської · дитяча рольова гра з ШІ-Ведучим

Веб-застосунок для **помічника ведучого** (дорослого), який проводить дитячу рольову гру (d6) разом із Ведучим-ШІ (Gemini). Діти грають наживо поруч, помічник передає їхні відповіді від імені персонажів.

- Потрібен власний безкоштовний ключ Gemini API (Google AI Studio). Ключ зберігається лише у вашому браузері.
- Застосунок для дорослих 18+. Не вводьте імен, віку чи інших особистих даних дітей.

Локальний запуск: `python3 -m http.server 8781 --directory app` і відкрити http://localhost:8781.
Оновити контент гри: `python3 app/tools/sync_content.py` (з папки проєкту).
