# S3А · Сад (розвилка 1, шлях А)
**Хід:** 1–2. **Обмін:** кошик і тихий вхід ↔ без Книги.
**Зображення:** BG-04 (сад), IT-07 (лише коли кошик отримано).
**Опис:** За будинком старий сад, огорожа з кущів, рядки полуниці й смородини, під грушею лійка, пахне ягодами.
**Інтерактивні об'єкти:** огорожа, стара груша, грядки полуниці, лійка.
**Задача для гравців:** огорожа з колючих кущів висока — як герой через неї перебереться? Спершу спитай план, кидок проси лише після нього.
**Виклик:** Спритність (Йо-йо) — гойднутися чи перестрибнути огорожу. Кидок: `kind: action`, `tags: ["S3А"]`.
**Успіх →** тихо через огорожу; **IT-07 Полуничний кошик** + заготовка **«Тихий вхід»** (`prepared_add`).
**Провал →** кущі чіпляють плащ, комічне ускладнення, ⭐ не знімається. Повтор один раз (бажано з Дружнім плечем, якщо поруч напарник): успіх дає кошик, але **без** тихого входу. Другий провал → сад пройдено без нагороди.
🔒 **Суперздібності (лише для Ведучого — коли гравці самі їх застосовують):**
| Супершанс | Котаклізм |
|---|---|
| Літаюча лійка чи драбинка-стрибалка → перебрались, кошик, тихий вхід | Огорожа з кущів → порох, прохід вільний; кошик є, але шумно — **без** тихого входу |
🔒 **Лише для Ведучого:** кошик і тихий вхід видаються лише після успішного кидка (чи суперздібності) — застосунок це перевіряє.
**Деталі сцени (для уточнень):** огорожа — по плечі, колючі гілки сплелися щільно; стара груша з товстою гілкою нависає просто над огорожею; під грушею — перевернута лійка; за кущами м'які грядки полуниці.
**Підказка 1:** гілка груші трохи гойдається на вітрі просто над колючками. **Підказка 2:** з груші зривається лист і, гойднувшись, перелітає через колючки.
**Виходи:** → S4. Леді Баг через чорний хід потрапляє в коридор першого поверху перед залом сухарів.
🔒 **Лише для Ведучого:** якщо герої розділились — після цієї сцени передай хід напарникові (S3Б); зустрічаються в коридорі першого поверху перед залом сухарів (S4).
