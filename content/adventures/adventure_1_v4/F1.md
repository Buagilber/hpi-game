# F1 · Хлібна броня та град кульок ⚠
**Зображення:** BG-11, EN-01, EV-01, EV-06, EV-02, IT-06, IT-07, IT-08, IT-09, NP-02.
**Образ:** ворог у товстій хлібній броні, під нею ледь видно фартух. Поки броня на ньому, до брошки не дістатися.

**Репертуар ворога (1 дія на раунд):**
1. **Град хлібних кульок** — захист (разом чи окремо). Перший хід фази. Якщо в S4 героїв помітили — перший захист без Дружнього плеча.
2. **Хлібна стіна** — одного героя затиснуто між хлібними стінами: цього раунду в нього лише проста дія, доки напарник не звільнить (складна дія).
3. *Умовно:* **Броня тремтить** — лише якщо герої невдало вдарили: він закриває тріщину, наступного раунду її треба шукати знову.

**Результат фази:** броня знята, видно фартух із брошкою. `shield_delta: -1`, `boss_phase: "F2"`.

| Що роблять гравці | Ефект |
|---|---|
| **Котаклізм** по броні | **Закриває фазу** одразу: броня розсипається на порох (без кидка) |
| Посох — удар у тріщину | **Закриває фазу**, коли набрано 2 успіхи: по одному від кожного героя **або один успішний спільний кидок (він рахується за 2)**. `tags: ["F1","armor"]` |
| Йо-йо — стягнути броню | **Закриває фазу**, коли набрано 2 успіхи (як вище; спільний успіх = 2). `tags: ["F1","armor"]` |
| Йо-йо — вирвати багет | Лише допомагає: кидок `tags: ["F1","baguette"]`; успіх — ворог збентежений і пропускає наступну дію, на броні тріщина (наступна дія проти броні з `idea: true`), багет застряє під піччю (EV-06). Щит не знімається |
| Мішок борошна (IT-06) | Лише допомагає: хмара показує тріщину; бонус на дію, що шукає тріщину, рахує застосунок (`tags` мають містити `"armor"`) |
| Супершанс | Лише допомагає: парасолька-щит (наступний захист автоматично чистий) або чарівна мітла (змітає крихти — ворог пропускає дію) |
| Термос / ягоди / Миска какао | Лише Підкріплення (+1 ⭐), фазу не закриває |
| Спогади | Тут ще не діють: крізь броню голос героїв до П'єра не долинає (можна сказати це в розповіді) |

**Провал удару чи захисту:** −1 ⭐ (крихти за комір), не більше одного за раунд; після невдалого удару ворог може скористатися «Броня тремтить».
**Підказка 1:** у броні видно тріщину, посох чує «глухий звук». **Підказка 2:** Софі з вікна: «Може, розсипати її одним чарівним дотиком? Чи вдарити в тріщину?» — вибір за гравцями.
**ЩВ:** Крокант-Мен спотикається об мішок джему (EV-02) → вікно.
**Виходи:** → F2.
