# F3 · Спогади і брошка ⚠
**Зображення:** EN-02 (на початку фази), IT-02 / IT-03 / IT-04 / IT-05 (лише Спогади, які є в отриманих предметах і які гравці показали), EV-03 (лише коли брошку зірвано), NP-02 (коли Софі гукає), IT-09 (термос як Підкріплення).
**Образ:** броні немає, багет м'який; пекар хитається, на фартуху пульсує темна брошка (EN-02).

**Слабке місце відкривається Спогадами:** гравці пред'являють ≥ 2 Спогади з **отриманих** (IT-02…IT-05; не згадуй тих, яких немає в стані) — кожен коротка репліка чи дія; П'єр м'якне: «Ці діти… я ж пік для них…»
- **Перший Спогад** — ворог розчулений і пропускає наступну дію.
- **Другий** — наступний захист від нього автоматично чистий (б'є мляво).
- Решта — лише слова (але ≥ 3 Спогадів дають бонус на зрив брошки — рахує застосунок).
Без двох Спогадів брошку не зірвати: удари лише хитають ворога. Якщо Спогадів менше двох — Софі нагадує з вікна, що вони могли принести.

**Репертуар ворога:**
1. **Сумний замах багетом** (чи рукавицею) — захист.
2. **«Не забирайте мою броню!»** — брошка ховається під фартух; щоб відкрити, потрібна проста дія.
3. *Реакція:* **Розчулення** — пропуск ходу після першого Спогаду.

**Результат фази:** брошку зірвано, метелик звільнений (EV-03). `shield_delta: -1` → S7.

🔒 **Лише для Ведучого — шляхи розв'язання (не переказуй гравцям як меню й не пропонуй предметів):**

| Що роблять гравці | Ефект |
|---|---|
| Йо-йо — зірвати брошку | **Закриває фазу** при 1 успіху (лише коли слабке місце відкрите). Кидок `LB` або `both`, `tags: ["F3","brooch"]` |
| Посох — відвести багет | Лише допомагає: підготовчий крок плану (`plan_step`) або спільна дія (`hero: "both"`) |
| Котаклізм по багету | Лише допомагає, без кидка: ворог без зброї — наступна дія з `idea: true` |
| Супершанс: магніт-метелик | Лише допомагає, без кидка: притягує брошку ближче — наступна дія з `idea: true` |
| Термос / Підкріплення | Лише +1 ⭐ |

**План:** «відвести багет → відкрити брошку → зірвати» — веди покроково, по кроку за раунд; застосунок рахує бонус повного плану, якщо кроки йдуть по порядку.
**Провал зриву:** брошка тримається, пекар хитається, повтор наступного раунду (Софі підбадьорює з вікна).
**Деталі сцени (для уточнень):** броні немає, пекар хитається й розгублено дивиться на свої руки; темна брошка на фартуху пульсує; коли хтось згадує дітей, він на мить завмирає.
**Підказка 1:** брошка пульсує, коли П'єр чує слово «діти». **Підказка 2:** Софі: «Згадайте, для кого він завжди пік найсмачніше!»
**ЩВ:** Софі вривається з какао: +1 ⭐ і вікно для підготовчої дії (відвести багет чи відкрити брошку). Саму брошку зривають кидком.
**Запасний фінал (програти не можна):** якщо після таймауту й ЩВ брошка все ще тримається — П'єр сам, зворушений Спогадами, тягнеться до брошки, а герої допомагають; наступний зрив вдається автоматично. Підкресли, що це сталося завдяки Спогадам, які принесли герої.
**Термос:** якщо після дії ворога в команди лишилась одна ⭐ і Термоса ще немає — Софі кидає його з вікна (IT-09).
**Виходи:** → S7.
